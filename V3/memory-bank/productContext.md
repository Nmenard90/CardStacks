# Product Context

The product exists because collectors need a faster and more reliable alternative to spreadsheets and disconnected price sites.

The central experience is:

1. Find the correct card quickly, including ambiguous collector numbers.
2. Record exactly what is owned with minimal friction.
3. Organize and understand the collection later through filters, binders, set completion, exports, and values.

Important experience rules:

- Common quick add should be simple.
- High-volume entry must be keyboard-efficient and resilient to request failure.
- Unknown prices must be shown as unknown, not zero.
- Public sharing must reveal only intentionally public binder data.
- Error messages should help a non-expert understand what happened and what to do next.
