## Reviewer feedback resolved

- Added a command-scoped placeholder `DATABASE_URL` for `prisma generate`. This removes the build's dependency on a local `.env` while keeping real credentials out of the build context and runtime image configuration.
- Regenerated Prisma Client inside the isolated `pnpm deploy` output because deployment reconstructs `@prisma/client` from the content-addressable store and otherwise restores its ungenerated stub.
- Limited the API package payload to `dist`, and hardened the runtime stage to run only the production deployment as the non-root `node` user.
- Removed the temporary repository-root `debug.Dockerfile` identified by the latest independent review; deployment continues to use only `apps/api/Dockerfile`.
- The deterministic Windows host subsequently verified the image build, non-root production startup, Prisma Client runtime load, and containerized `/health` response.
