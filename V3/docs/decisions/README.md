# Architecture Decision Records

Create one Markdown file per durable decision using this naming pattern:

```text
ADR-001-short-decision-name.md
```

Template:

```markdown
# ADR-001 — Decision Title

- Status: Proposed | Accepted | Superseded
- Date: YYYY-MM-DD

## Context

## Decision

## Alternatives Considered

## Consequences

## Follow-up Work
```

Create ADRs for decisions involving authentication, public API contracts, search/indexing, import/export formats, pricing providers/mappings, master-set variant rules, deployment architecture, or billing/access enforcement.
